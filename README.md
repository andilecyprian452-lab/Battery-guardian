# Battery-guardian
Battery Guardian Android app fo monitoring battery temperature and providing cooling reminders and safety tips
FEATURES :
*Display battery temperature when supported by the device
*Provide reminders when a battery becomes too hot
*Offer battery cooling and charging safety tips
*Help users understand when to wait before charging again

DEVELOPMENT :
Battery Guardian is currently being developed. The web preview may not be able to access the phone's actual battery temperature. Native Android development will be needed to investigate access to device temperature reading.  

GOAL
To help make inforned decisions about battery heat and charging safety.
